# Bouncing Ball

A pixel-art physics platformer about a little tumbler riding a bouncy red ball. Lean, charge and jump through three handmade levels, a boss fight and an Endless Run. Every fall is a chance to bounce back.

## Try it
https://thanhbc1234.itch.io/bouncing-ball

## Features
- Lean and charge with A / D, jump with Space / W / Up; every landing bounces like a real ball
- Three story levels (First Bounce, Seesaw Valley, Boss Arena) with 3 hidden stars in each
- Find out yourself when play our game ^_^
